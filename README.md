# Hanpath — Mandarin Flashcards

A PWA for learning Mandarin with spaced repetition. Inspired by
[Deckr](https://deckr.wiesnermartin.com/), rebuilt from scratch for Mandarin:
**4,989 HSK 1–6 words**, 16 cross-level domain packs, browser text-to-speech,
fully offline. No build step, no framework, no backend.

## Features

- **Spaced repetition (SRS)** — simplified SM-2: Again / Hard / Good / Easy
  grading, intervals from 10 minutes up to a year, mastery = interval ≥ 21 days.
- **HSK path** — level 2 opens when level 1 hits 65% mastery (like Deckr's
  path, which opens the next deck at the same threshold).
- **Domain packs** — Food, Travel, Body & Health, Tech, Feelings, … Each pulls
  matching words from every level you've unlocked.
- **Two quiz modes** — tap-to-flip with grading, or multiple choice.
- **Audio** — every word speaks via the Web Speech API (`zh-CN` voice), with a
  speed setting.
- **Stats** — streak, 14-day review chart, unique characters seen, 30-day
  accuracy.
- **Offline** — service worker caches the whole app shell and data.
- **Local-only progress** — lives in the browser's localStorage; JSON backup
  export/import (merged, never overwritten).

## Run locally

```sh
cd LearnChinese
python3 -m http.server 8642
# open http://localhost:8642
```

Any static file server works. The service worker only registers on `https://`
or `localhost`, so plain `file://` won't cache — use a server.

## Project structure

```
index.html            app shell (loads the three JS files, nothing else)
css/styles.css        all styling, light + dark theme via CSS variables
js/srs.js             spaced repetition engine (pure functions, no DOM)
js/tts.js             Web Speech API wrapper, picks a Chinese voice
js/app.js             everything else: router, views, quiz, stats, settings
data/hsk1..6.json     word lists: [{id, h: hanzi, p: pinyin, e: [english], l, d}]
data/domains.json     domain → level → word ids, plus labels & counts
manifest.webmanifest  PWA manifest (name, icons, standalone display)
sw.js                 service worker, cache-first offline
icons/                192px + 512px icons (also apple-touch-icon)
scripts/build_data.py builds data/*.json from the raw HSK dump
scripts/make_icons.py generated the icons
```

## Editing data

The `data/*.json` files are generated by `scripts/build_data.py` from a flat
HSK 1–6 dump (2.2 MB, ~5,000 entries with hanzi / pinyin / English glosses).
The script also auto-tags each word with a domain by keyword-matching its
English glosses. If you change the tagging rules or add a data source, re-run:

```sh
HSK_SRC=/path/to/source.json python3 scripts/build_data.py
```

## Changing code

Bump `CACHE_VERSION` in `sw.js` whenever you change any cached file, or
returning visitors will keep the old version until their browser re-checks.
